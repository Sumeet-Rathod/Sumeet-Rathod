## ⚡ What Is Inside This Project?

This project is a direct answer to OnArrival's challenge: *"Show, don't tell."*

Instead of just submitting a resume, this project delivers:
1. **The Segment Landing Page:** Tailored for pre-seed & seed founders, AI agent builders, and fintech teams who want to avoid 18 months and ₹2 Crores in legacy airline GDS contracts.
2. **Interactive Live Sandbox Console:** Real-time simulated flight search API requests with cURL, Python, and TypeScript snippet toggles.
3. **Net Take-Rate & Margin Calculator:** Dynamic real-time margin estimator answering how businesses make money on OnArrival.
4. **90-Day GTM & Funnel Playbook:** The execution blueprint for optimizing `Discover → Sign Up → Sandbox → First API Call → Live Credentials`.
5. **3 Ready-to-Ship Content Campaigns:** Ready-to-shoot reel storyboards (Claude MCP + HeyGen/Higgsfield), LinkedIn carousels, and developer teardown threads.

## 🚀 How to Run Locally

### Option 1: Open Directly in Browser
Double-click `index.html` or open it with any browser:
```bash
start index.html   # On Windows PowerShell
```

### Option 2: Run with Python HTTP Server
```bash
python -m http.server 8080
# Visit http://localhost:8080 in your browser
```

### Option 3: Deploy to Vercel / Netlify in 30 Seconds
```bash
npx vercel
# Follow the prompts to get an instant public URL (e.g., https://onarrival-growth-sumeet.vercel.app)
```
